# DFIR-Digital-forensics-and-incident-respond-_Journey
This repository contains my 12-Month DFIR (Digital forensics and incident response) journey from beginner to job ready, including monthly plans, hands on labs, projects and Forensics report writing. 

## Month 1 - NETWORKING
- Networking is the most important yet fundamental subject in the journey of DFIR.
- Imagine it as like if you dont know what to secure, then how will you secure systems ?
- if you don't know how systems in a network work, how data is transferred, then what will you do at the time of real attack simulation !
